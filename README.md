# AI Langton's Ant Lab

AI によって作成された、ラングトンのアリをブラウザ上で実験するためのシミュレーターです。

## 機能

- 盤面サイズと各セルの初期色を編集
- 複数のアリの初期位置と向きを編集
- 最大16色と色ごとの回転規則を編集
- 再生、停止、1ステップずつの実行
- 開始ステップと任意ステップへの移動
- 現在の設定と再生位置をURLに含めて共有
- デスクトップとモバイルの両方に対応

## 実行方法

追加の依存関係やビルド処理はありません。`dist/index.html` をブラウザで開くか、任意の静的Webサーバーから `dist` ディレクトリを配信してください。

## GitHub Pages

`main` ブランチへ変更を送信すると、GitHub Actions が `dist` ディレクトリをGitHub Pagesへ公開します。ワークフローは初回実行時にPagesを有効化する設定を含みます。

## 技術構成

- HTML
- CSS
- JavaScript
- Canvas API

盤面、アリ、色ルール、開始ステップはURLのハッシュにJSONをBase64URL形式で格納します。サーバーへの状態保存は行いません。
